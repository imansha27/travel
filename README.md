# travel
** Travel Pass with NFC Technology and QR Code

NFC Travel Pass: Purchase at airports upon arrival. After providing personal and visa details, travelers can choose from five packages based on travel duration and transportation preferences.

Easy Website Access: QR code on the pass directs users to our website. After logging in, travelers can view hotel details, locations, transportation info, and recharge their pass online.

Customizable Packages: Visit up to 20 pre-selected locations and add more by recharging. Packages cater to both adults and children.

Financial Transparency: Track expenses and remaining balance of the package through our website.

User Registration: Registered users enjoy full access to packages, travel cards, activity bookings, and online guides. Unregistered users can explore the home and hotels pages.

Admin Capabilities: Admins have unrestricted access to manage the system and oversee travel pass data.
Bus Booking System: Users can view bus schedules across the country for convenient transportation planning.

Technical Stack:
We used the MERN Stack (MongoDB, Express, React, Node.js) for developing our robust and dynamic website.

Payment Integration:
Integrated the PayPal Sandbox API for secure and efficient payment solutions.

Problem Addressed:
Aims to restore confidence and convenience for travelers in Sri Lanka, promoting a safer and more enjoyable travel experience.
